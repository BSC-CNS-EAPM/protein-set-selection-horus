Cluster job settings#

Every block that can run as a SLURM job (ProteinMPNN Scoring, MMseqs2 Clustering, Rosetta Relax, BioEmu Sampling) has these settings, shown under Slurm configuration in the block. On the Local remote only CPUs matters: it sets how many jobs run in parallel. See Remotes and clusters for how to choose values.

Setting

Type

Default

Description

Script name (script_name)

string

calculation_script.sh

Name of the generated job script. Change it only to run two calculations of the same block in one folder.

Partition / QOS (partition)

string

gp_bscls

Queue to submit to, as your cluster names it. On MareNostrum 5 it is the QOS: gp_* for general-purpose CPU, acc_* for GPU, *_debug for short test runs. Elsewhere it is written as --partition, unless it is given as 'qos:<name>'.

Account (account)

string

—

Account (project) to charge the job to, when the cluster needs one. Leave empty to let the cluster pick your default; on MareNostrum 5 the bsc_calculations default is used instead.

Extra SBATCH lines (sbatch_extra)

string

—

Additional SBATCH directives for clusters other than MareNostrum, one per line and without the '#SBATCH' prefix, for example '--mem-per-cpu=4G' or '--nodes=1'.

CPUs (cpus)

integer

1

Number of CPUs to use. On a cluster this sets the job's tasks/CPUs; running locally it sets how many jobs run in parallel (capped by the number of jobs).

CPUs per task (cpus_per_task)

integer

1

CPUs given to each task (OpenMP/threads). Most blocks use one; MMseqs2 uses it as its thread count.

Walltime (hours) (time)

integer

0

Wall clock limit in hours. bsc_calculations clamps this to the QOS cap (2h on the *_debug queues), and a request far above what a job needs only makes it queue longer. 0 leaves the bsc_calculations default of 48h.

Group jobs per array task (group_jobs_by)

integer

0

Bundle this many jobs into each array task, run one after another. One array task per job is right for long jobs, but for jobs of a few minutes the queue wait dominates: ten one-minute jobs each wait separately. Setting this to the number of jobs runs them all in a single task. 0 keeps one task per job.

Environment variables (environment_list)

list

—

Environment variables to set during the remote connection. Each entry has: environment_key (string), environment_value (string).

Remove remote folder on finish (remove_folder_on_finish)

boolean

True

Deletes the calculation folder on the remote on finish.
